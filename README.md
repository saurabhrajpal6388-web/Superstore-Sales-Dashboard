# 📊 Superstore Sales Dashboard

An interactive **Superstore Sales Dashboard** created using Microsoft Excel to analyze sales performance, profitability, customers, products, and regional trends.

This project transforms raw Superstore sales data into an easy-to-understand interactive dashboard that can be used for business analysis and decision-making.

---

## 📌 Project Overview

The objective of this project is to analyze Superstore sales data and identify important business insights related to:

- Sales performance
- Profitability
- Orders
- Customers
- Products
- Categories
- Sub-Categories
- Regions
- States
- Monthly and yearly trends

The dashboard provides a visual summary of the business performance and helps identify areas of growth and improvement.

---

## 🛠️ Tools & Technologies

- **Microsoft Excel**
- Pivot Tables
- Pivot Charts
- Excel Charts
- Slicers
- Data Cleaning
- Data Analysis
- Data Visualization
- Conditional Formatting
- Excel Formulas
