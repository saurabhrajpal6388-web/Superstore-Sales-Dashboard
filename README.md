# 📊 Superstore Sales Dashboard

## 📌 Project Overview

The **Superstore Sales Dashboard** is a data visualization project designed to analyze sales performance, customer purchasing behavior, regional transactions, and product category performance.

The dashboard provides an interactive view of key business metrics, helping users identify sales trends, understand regional performance, and make data-driven business decisions.

## 🎯 Project Objectives

* Analyze overall sales performance using key performance indicators (KPIs).
* Compare sales distribution across different shipping modes.
* Analyze transactions across different geographical regions.
* Identify monthly trends in quantity ordered.
* Identify the top-performing cities based on sales.
* Analyze transactions across product categories.
* Understand quantity ordered by consumer segment.
* Provide an interactive dashboard for exploring business performance.

## 📈 Dashboard Highlights

### 1. Key Performance Indicators (KPIs)

The dashboard displays the following metrics:

| Metric                 |     Value |
| ---------------------- | --------: |
| Total Sales            | 18,56,076 |
| Average Sales          |    560.41 |
| Total Transactions     |     3,312 |
| Total Quantity Ordered |     8,314 |

### 2. Ship Mode Sales Distribution

Visualizes the percentage distribution of sales across four shipping modes:

* First Class
* Same Day
* Second Class
* Standard Class

This analysis helps compare shipping preferences and understand the contribution of each shipping mode.

### 3. Region-Wise Transactions

Displays transaction distribution across four regions:

* Central
* East
* South
* West

This visualization helps compare regional business activity.

### 4. Monthly Quantity Ordered

A line chart illustrates the quantity ordered throughout the year, helping identify monthly fluctuations, high-demand periods, and potential seasonal trends.

### 5. Top 5 Cities by Sales

A bar chart highlights the top five cities based on sales:

* New York City
* Seattle
* Los Angeles
* Philadelphia
* San Francisco

This analysis helps identify major city-level sales contributors.

### 6. Category-Wise Transactions

Compares transactions across three product categories:

* Technology
* Office Supplies
* Furniture

This visualization provides insights into transaction distribution across product categories.

### 7. Consumer Segment Analysis

Displays the quantity ordered by customer segment:

* Consumer
* Corporate
* Home Office

This analysis helps understand purchasing behavior across different customer segments.

## 🛠️ Tools & Technologies

* **Microsoft Excel** — Dashboard development and data visualization
* **Excel Charts** — Visual representation of business metrics
* **Excel Slicers** — Interactive filtering by region and year
* **Data Analysis** — Sales performance and customer behavior analysis

## 🎛️ Interactive Features

The dashboard includes interactive filters that allow users to explore the data by:

* **Region:** Central, East, South, and West
* **Year:** Filter sales and performance metrics for different years

These interactive controls make it easier to analyze specific business segments and compare performance across different periods.

## 🚀 How to Use This Project

1. Download or clone this repository.
2. Open the Excel workbook in Microsoft Excel.
3. Navigate to the dashboard worksheet.
4. Use the region and year slicers to filter the data.
5. Explore the charts and KPIs to understand sales performance.
6. Change the filters to compare different regions and time periods.
